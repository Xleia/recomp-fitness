# 第一阶段回归与验收记录

## 自动验证

`node --test tests/*.test.cjs`（Node 20+，无第三方依赖）。使用虚构记录，不操作用户真实保险库。测试包括：

- F01：JSON 字典/数组无损视图、日期边界、空记录、零值/空值、CSV 中文日文/引号/换行/公式型文本、done===true 完成统计、迁移副本和旧摘要去重。
- F02：默认计划每个动作/顺序/组数/次数/休息/RIR 与迁移前公共模板一致；非法结构和范围、重复 ID/星期/顺序、周次覆盖、默认文件加载失败重试。
- 旧记录按自己的动作和组数回显；旧记录手动保存保留附加字段，不补造计划关联；新记录的建议模板与实际数据分开保存。
- F03：预览/取消不落盘；仅保存不切换；启用/回退/恢复默认保留历史版本；相同 ID/版本需确认副本；损坏计划库回退而不删除数据。
- 实际 PBKDF2/AES-GCM 加密解密：旧备份无计划字段仍能往返；新备份携带版本库；重建应用上下文后无需默认网络文件即可读取已保存启用计划。
- 存储失败回滚内存及磁盘；导入读取中途取消、确认保存后加密中取消；锁定中止；私有预览清理。
- 代码语法、离线资源清单及远程 Git blob 与本地源码逐文件比对。

测试使用轻量 DOM 事件模拟，并不等于真实浏览器或真实设备验收。
